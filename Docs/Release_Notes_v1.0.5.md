# 地球Online v1.0.5 Release Notes（发布文案草案）

> 用途：用户手动创建 GitHub Release（tag v1.0.5）时直接粘贴。发布前请确认四端版本号均已同步至 1.0.5，并附上构建产物。

---

## 版本概览

地球Online v1.0.5 全量迭代版本。Web / Android / Windows / iOS 四端版本号统一升级至 1.0.5，iOS 端新增回收站、全局搜索、记忆相册、CSV/Markdown 导入、人生卡片分享等十余项功能，并补齐全部 47 项成就（与 Android 基线零偏差）。

## ⚠️ 重要升级须知（请务必阅读）

- **Android 端（核心警示）**：本次起 Android 端从 debug 签名切换为正式签名，**新旧签名不兼容，直接覆盖安装旧版本会失败**。请先卸载旧版再安装新版；如本地有未同步数据，请先在旧版中执行「设置 → 导出数据」备份，装好新版后再「导入数据」恢复。
- **iOS 端**：为未签名 ipa，通过 SideStore 覆盖安装即可，无需卸载旧版；签名 7 天有效，注意定期续签。数据照常通过 WebDAV 同步，覆盖安装不丢数据。
- **Windows 端**：直接运行新版安装器覆盖安装，用户数据目录不受影响。

## 功能亮点

- **回收站**：任务 / 日志 / 物品 / 收藏 / 足迹删除后先进回收站，30 天内可恢复，超期自动清理；回收站内容不参与四端同步，不影响其他端数据。
- **全局搜索**：一个入口通查任务、日志、物品、收藏与足迹。
- **记忆相册（iOS）**：支持一次多选导入照片，自动落盘保存。
- **导入增强（iOS）**：支持 CSV 任务表与 Markdown 日记导入，按主键合并不覆盖已有数据。
- **人生卡片（iOS）**：一键生成个人成长长图（等级 / 连续记录 / 本月关键词），分享给你的伙伴。
- **灵感接力（iOS）**：随手记一条灵感，1 小时后本地通知提醒，一键转为待办。
- **历年今日（iOS）**：首页回看往年同月同日的记录与足迹。
- **庆祝反馈与连续记录**：完成任务触觉反馈+光晕（连击渐强）；新增「当前连续」记录口径。
- **成就体系**：四端成就对齐至 Android canonical 47 项，新增空白标题 / 时光回声 / 记忆管理员等隐藏彩蛋。

## 修复与优化

- iOS：AI 对话防并发请求；小组件深色模式取色适配；同步结果实时反馈；自动拉取 5 分钟节流；连接测试错误统一中文提示；版本检查与更新引导（SideStore 场景）。
- 同步契约保持不变：earth-online-backup.json，字段 camelCase，WebDAV 按主键合并。

## 下载与安装

- **Android**：`EarthOnline-v1.0.5-release.apk`（正式签名，见 Release 附件）。⚠️ 先卸载旧版再安装。
- **Windows**：`EarthOnline-Windows-v1.0.5-win-x64.exe` 与单文件安装器 `EarthOnline-Windows-Setup-v1.0.5-win-x64.exe`。
- **iOS**：`EarthOnline-iOS-v1.0.5-2-unsigned.ipa`（未签名，SideStore 安装；Release 附件与 GitHub Actions Artifact 均可获取）。
- **Web**：线上站点直接访问，刷新即最新。
